Privacy

This website

This site sets no cookies, uses no analytics and loads nothing from other sites except one request: your browser asks the public GitHub API for the newest Nitrate release, so the download buttons can link its files. GitHub receives that request like any other visit to GitHub. The site is hosted on GitHub Pages, which logs visitor IP addresses in its own server logs; see the GitHub privacy statement.

Nitrate

Nitrate has no account and no telemetry. It plays the files you open and sends nothing about them anywhere.

An installed copy asks the public GitHub API once a day whether a newer Nitrate release exists. That request carries no information about you or your files beyond what any web request does. When you press Ctrl+Shift+U to install an update, Nitrate downloads the setup and its checksum file from GitHub. The portable zip never checks, and setting the environment variable NITRATE_NO_UPDATE turns checks off.
