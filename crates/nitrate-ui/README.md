# nitrate-ui

The player controls of [Nitrate](https://github.com/rennerdo30/nitrate): layout, hit testing, a damage-quantised view model and CPU drawing into premultiplied RGBA layers (tiny-skia, fontdue). No windowing and no GPU code; the app composites the layers over the video.

Part of the Nitrate media player and published for it; the API follows Nitrate's needs and may change between versions. MIT licensed.
