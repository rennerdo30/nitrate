# nitrate-update

Update checks for [Nitrate](https://github.com/rennerdo30/nitrate): GitHub release discovery, SemVer ordering with beta and stable channels, `SHA256SUMS.txt` verification and bounded HTTPS downloads. On Windows these go through WinHTTP, so system proxy settings apply. Only GitHub hosts are contacted.

Part of the Nitrate media player and published for it; the API follows Nitrate's needs and may change between versions. MIT licensed.
